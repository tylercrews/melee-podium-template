9:55 PM






Don’t comment them out. Archive the portrait files outside char_assets/renders, for example:
char_assets/archive/Bowser/00b_default_Bowser_melee.png
char_assets/archive/Bowser/01b_red_Bowser_melee.png
...
Move every color variant for that pose. Since the API only scans char_assets/renders, the archived pose immediately disappears from the frontend selection list—no code changes needed.
You can leave its entries in [portrait_pose_labels.py (line 1)](C:\\Users\\tycre\\Desktop\\02.Coding\\melee-podium-template\\portrait_pose_labels.py:1) and the scale file; they are harmless and make restoring the pose as simple as moving the files back. Remove those entries only when you are certain it is permanently retired.
One caveat: update any saved favorites that explicitly use that pose. Otherwise, an old favorite could request an asset that no longer exists and the renderer will reject it.
