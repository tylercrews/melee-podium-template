It wouldn’t match if the dictionary’s actual key is still tyRo—object/dictionary keys are case-sensitive.
You have two options:
// Normalize both sides while comparing
favorites.find(
  favorite => favorite.tag.trim().toLowerCase() === input.trim().toLowerCase()
)
That’s what the app currently does.
Or, for a real lookup map, normalize when building the map and when querying:
const byTag = new Map(
  favorites.map(favorite => [favorite.tag.trim().toLowerCase(), favorite]),
);

const match = byTag.get(input.trim().toLowerCase());
Here the stored key is tyro, even though favorite.tag retains tyRo (or Tyro) for display.
