No—you can derive secondary positions from each existing podium anchor.
Use a small helper that evenly spaces a player’s character anchors around the normal center anchor:
def _character_anchors(anchor: tuple[int, int], count: int, spacing: int = 70):
    center_x, y = anchor
    return [
        (round(center_x + (index - (count - 1) / 2) * spacing), y)
        for index in range(count)
    ]
That gives:
1: center
2: left, right
3: left, center, right
4: far left, left, right, far right
5: far left, left, center, right, far right
Then change _place_characters to generate these anchors and place each portrait at its corresponding position instead of passing every portrait the same anchor.
This is cleaner than storing secondary anchors for every podium: your current SINGLES_ANCHORS remains the canonical center point, while spacing can be one global constant—or a small per-layout setting if Top 8 needs a tighter spread. I’d avoid repeating center, left, right once there are more than three, since it starts reintroducing the exact overlap you’re trying to remove.

That makes sense—and it fits the renderer’s current tallest-to-shortest draw order perfectly.
Use a repeating offset sequence rather than evenly expanding outward:
MULTI_CHARACTER_X_OFFSETS = (0, -70, 70)  # center, left, right
Then, inside _place_characters, apply it as each already-sorted portrait is drawn:
placements = [
    _place_image(
        canvas,
        image,
        (anchor[0] + MULTI_CHARACTER_X_OFFSETS[index % 3], anchor[1]),
    )
    for index, image in enumerate(draw_order)
]
So the largest three establish the main silhouette at center/left/right; characters 4–6 reuse those positions and naturally layer over them, but should be smaller because of the existing height sort.
Still no secondary anchor maps needed—just one reusable horizontal offset constant. You could later make 70 layout-specific if Top 8 needs a tighter 40–50px spread.
